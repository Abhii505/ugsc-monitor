About the WQI Method (Weighted Arithmetic)
Parameters used: pH, Turbidity, and TDS (estimated = 0.64 × Specific Conductance). Water temperature is excluded because BIS/WHO has no numeric drinking water limit for it.
K = 1 / Σ(1 / Si)
Wi = K / Si
qi = 100 × |Vi − Vid| / (Si − Vid)
WQI = Σ(qi × Wi) / ΣWi
Standards (Si) & Ideal Values (Vid):
• pH: Si = 8.5, Vid = 7.0 (Wi ≈ 0.3681)
• Turbidity: Si = 5.0 FNU/NTU, Vid = 0 (Wi ≈ 0.6257)
• TDS (est.): Si = 500 mg/L, Vid = 0 (Wi ≈ 0.0063)
Constant K ≈ 3.1285, ΣWi = 1.0000.
